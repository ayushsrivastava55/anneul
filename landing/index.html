The agent that engineers agents, then makes them cheap. The loop

Spec goal + tools + eval→ Architect 3–4 topologies→ Run traced, parallel→ Diagnose typed taxonomy→ Mutate typed operators→ Gate holdout ×3, sign test→ Anneal tier downshift→ Ship

An honest gate

One-sided sign test on a reserved split the optimiser never sees. When a candidate is ahead but the sample is too small for any verdict, the gate buys a second block of runs instead of publishing a false “no effect”. Rejections are shown, not hidden — that is the feature.

Memory that grows

A persistent issue ledger plus episodic and procedural memory (SQLite FTS5): rules learned from failed traces, credited when they help, retired when they stop helping. Every prompt edit is versioned in the Neatlogs registry.

Builds its own tools via AO

When diagnosis finds a missing capability, Anneal spawns an AO worker session that writes the tool and its tests; the branch is accepted only when pytest passes. The optimiser used the orchestrator as its own hands.
