## Devpost fields

**One sentence:** Anneal turns goal.md + tools + eval.py into a production agent harness:
it searches architectures, diagnoses failures from traces into a typed taxonomy, applies
typed repairs behind a statistically honest promotion gate, then anneals the winner down
the model-price ladder — invoices hit a perfect 1.000 at 29× lower cost.

**How we used AO (required):** AO was our build environment and part of the product. The
project ran as AO project `anneal` with the daemon API (`127.0.0.1:3001`) driven from
`anneal/ao.py`. Sessions: the main orchestrator build sessions; `anneal-2`, a worker that
wrote `scripts/update_readme_results.py` (accepted after its pytest suite passed);
`anneal-3`, spawned *by the optimizer itself* when diagnosis found a missing capability —
it wrote the `run_pytest` tool plus acceptance tests, and Anneal's gate evaluated the
resulting agent. Worker harness: Claude Code. A daemon selftest ships in the repo
(`python -m anneal.ao --selftest`).

**Sponsor tech:** Neatlogs (all runs traced; typed diagnosis reads spans; prompt registry
versions every operator edit with staging/production labels), TensorMux (GLM-4.7-Flash as
the `flash` tier with built-in 429 backoff for its 60 RPM cap), AI Grants India
(gpt-5-nano as the `nano` tier — the invoices winner), Anthropic (frontier/mid/cheap
tiers). Dodo Payments: not wired (no key obtained); the $/task the optimizer reports is
the number a usage meter would bill.

**What improved across iterations (required by rules):** see README Results table —
generated by `scripts/update_readme_results.py` from `runs/`, never hand-edited.
